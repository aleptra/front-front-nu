This guide explains how to paginate a complete data collection in the browser using Front's Data module. Client-side paging fetches the collection once, then displays a smaller slice of the data for each page.

How It Works

Add paging attributes to the element that contains data-src and data-iterate:

  • data-page — The current page number. Pages start at 1.
  • data-pagesize — The number of items displayed per page. The default is 10.
  • data-limit — Optional. Limits the collection before paging is applied.

The Data module sorts and filters the collection first, then applies the page size and current page. The complete response remains cached by the module while the user changes pages.

Basic Example

Fetch the complete country collection and display five countries at a time. Use the Preview tab to run this example:

FTML <div id="paging-features" data-src="/assets/json/data/dummy.json" data-iterate="results" data-page="1" data-pagesize="5"> <div padding="0.5rem" borderbottom="1px solid white03"> <b data-get="name"></b> </div> </div> <div flex gap="2rem" margintop="1rem"> <button click="data-previous:#paging-features" ondata-firstpage="disable" ondata-notfirstpage="enable" disable>Previous</button> <button click="data-next:#paging-features" ondata-lastpage="disable" ondata-notlastpage="enable">Next</button> </div>

Paging Controls

Previous and Next

Use data-previous and data-next actions with the selector of the paged element:

FTML <button click="data-previous:#products">Previous</button> <button click="data-next:#products">Next</button>

Go To a Page

Use data-goto to jump to a specific page. The page number is clamped to the available range.

FTML <button click="data-goto:#products:[1]">Page 1</button> <button click="data-goto:#products:[2]">Page 2</button> <button click="data-goto:#products:[3]">Page 3</button>

Boundary Events

The Data module updates paging controls when the first or last page is reached. Use these events to disable buttons at the boundaries:

  • ondata-firstpage — Triggered when arriving at the first page.
  • ondata-notfirstpage — Triggered when leaving the first page.
  • ondata-lastpage — Triggered when arriving at the last page.
  • ondata-notlastpage — Triggered when leaving the last page.
FTML <button click="data-previous:#products" ondata-firstpage="disable" ondata-notfirstpage="enable" disable>Previous</button> <button click="data-next:#products" ondata-lastpage="disable" ondata-notlastpage="enable">Next</button>
